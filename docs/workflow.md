## Workflow de développement

### **Branches Git**
- `main` : stable  
- `dev` : développement  
- `feature/<nom>` : fonctionnalités

### **Processus**
1. Créer branche `feature/...`
2. Développer
3. Ouvrir une PR vers `dev`
4. Code review par un autre membre de l'équipe
5. Merge
